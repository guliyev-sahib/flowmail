# Contributing to Flowmail

Thanks for your interest! Flowmail is open-core: the code here is AGPL-3.0 and free
to self-host. Contributions that improve the core product are very welcome.

## Getting started

1. `./setup.sh` — bootstraps the app and installs dependencies
2. `cp .env.example .env` and fill in your dev credentials
3. `npm run dev`

## Where to help

- Good first issues are labeled `good-first-issue`.
- The current priority is the **abandoned cart flow** (see [ROADMAP.md](./ROADMAP.md)).
- Email templates, deliverability, and Shopify integration depth are always valuable.

## Ground rules

- Keep PRs focused and small.
- Match the existing code style; run the formatter before committing.
- By contributing you agree your work is licensed under AGPL-3.0.

## Not sure where to start?

Open a discussion or an issue describing what you'd like to work on. We'd rather talk
first than have you build something that doesn't fit the roadmap.
